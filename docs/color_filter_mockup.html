결재 상세페이지 — J/O-layer 색상 적용 기능 목업

현재 코드(ApprovalPage.tsx · PagedDetailView.tsx · FilterManageModal.tsx)의 실제 CSS 변수·클래스를 그대로 사용해 만든 화면 검토용 목업입니다. 실제 구현 전, 동작 흐름을 미리 클릭해볼 수 있습니다.

검토용 목업입니다. 실제 데이터/서버 연동은 없으며, 버튼 클릭 시 브라우저 안에서만 즉시 반영됩니다(새로고침하면 초기 상태로 돌아갑니다). 기존 "공유 필터" 줄은 실제 화면 그대로 두고, 그 아래 "색상 적용" 줄이 이번에 새로 추가되는 부분입니다.

1J-ayer 정보 탭 — 표 위 툴바

기존 공유 필터 줄은 그대로 유지, 그 아래 색상 적용 줄이 신규 추가됩니다. 색상 칩을 눌러보세요(여러 개 동시 ON 가능) — 아래 표의 매칭된 셀 색이 즉시 바뀝니다.
