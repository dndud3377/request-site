결재 상세페이지 — J/O-layer 색상 적용 기능 목업 (v2)

현재 코드(ApprovalPage.tsx · PagedDetailView.tsx · FilterManageModal.tsx)의 실제 CSS 변수·클래스를 그대로 사용해 만든 화면 검토용 목업입니다.

v3 수정 사항 — ① 키워드 추가 흐름 변경: 이제 키워드를 먼저 추가하면, 그 키워드 줄에 뜨는 색상 버튼을 눌러야 색을 고를 수 있습니다(공지 작성 화면의 글자색·바탕색과 동일한 "테마 색상 / 표준 색상" 팔레트 재사용). ② STEPSEQ/STEP 설명/PPID 구분에 쓰던 파란색·초록색·주황색 색칠을 없애고 이름 그대로 텍스트로 표시(실제 적용 색상과 겹쳐 헷갈리는 것을 방지).
v2 수정 사항 — ① 필터 하나에 색이 하나가 아니라, 키워드마다 각자 다른 색을 지정할 수 있도록 변경. ② "색상 관리" 버튼 옆에 전용 "초기화" 버튼을 추가해 적용해 둔 색상 토글을 한 번에 끌 수 있게 함(기존 "공유 필터"의 초기화 버튼과 같은 자리 배치·같은 UI 톤을 그대로 재사용).
검토용 목업입니다. 실제 데이터/서버 연동은 없으며, 버튼 클릭 시 브라우저 안에서만 즉시 반영됩니다(새로고침하면 초기 상태로 돌아갑니다).

1J-ayer 정보 탭 — 표 위 툴바

기존 공유 필터 줄은 그대로 유지, 그 아래 색상 적용 줄이 신규 추가됩니다. 색상 칩을 눌러보세요(여러 개 동시 ON 가능) — 아래 표의 매칭된 셀 색이 즉시 바뀝니다. 칩의 점 여러 개는 그 필터 안에 서로 다른 색의 키워드가 몇 개 들어있는지 보여줍니다.

2"🎨 색상 관리" 클릭 → 관리 모달 (키워드별 색상 지정)

필터 하나("장비특이" 등) 안에 STEPSEQ/STEP설명/PPID별로 여러 키워드를 넣을 수 있고, 키워드 하나하나마다 색을 따로 고를 수 있습니다. 흐름: 먼저 키워드를 입력해 "+ 추가"로 목록에 넣고 → 목록에 추가된 그 키워드 줄의 색상 버튼을 클릭해 팔레트에서 원하는 색을 고릅니다(공지 작성 화면의 글자색·바탕색 선택과 동일한 "테마 색상 / 표준 색상" 팔레트).

4"초기화" 버튼 동작

"색상 관리" 옆 전용 초기화 버튼을 누르면(위 1·3번 툴바에 이미 있습니다) 확인창 후 켜져 있던 색상 칩이 전부 OFF로 바뀝니다. 저장된 필터·키워드·색상 지정 자체는 지워지지 않고, 현재 켜둔 표시만 초기화됩니다 — 기존 "공유 필터"의 초기화 버튼과 같은 위치·같은 버튼 스타일을 그대로 따릅니다(동작 대상만 다름: 그쪽은 데이터, 이쪽은 화면 표시).
