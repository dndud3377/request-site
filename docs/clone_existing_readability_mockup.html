CLONE·EXISTING 상신서 — 의뢰 상세 모달 'R' 탭 가독성 개선안

결재 현황 → 의뢰서 행 클릭 → 의뢰 상세 모달 → 'R' 탭. 왼쪽은 현재 코드(PagedDetailView.tsx)가 그리는 화면을 그대로 옮긴 것이고, 오른쪽은 개선안 ①~⑤를 모두 반영한 화면이다. 위 버튼으로 케이스를 바꿔 볼 수 있다. 보라색 번호 배지와 점선은 설명용 표시이며 실제 화면에는 넣지 않는다.

1상단 요약 배너

MAP 목적과 "아래 잠긴 항목은 원본 MAP을 따른다"는 사실을 맨 위 한 줄로 먼저 알린다.

2원본 → 대상 칸

원본 위치·원본 제품 두 칸을 원본 → 이번 의뢰 한 칸으로 합친다. 원본과 대상이 같으면 "동일" 표시.

3잠긴 항목 접기

"없음" 칸 5~6개를 한 줄로 접고, 펼치면 항목별로 볼 수 있게 한다.

4"없음" → "원본 따름"

잠긴 항목 문구를 "원본 따름"으로 통일한다. X표시처럼 진한 "없음"으로 나오던 항목도 같은 모양으로 맞춘다.

5입력 항목 한 줄 압축

Only C가문 제품 · PY 적용 여부 · Final/GDS 를 한 칸에 나란히 놓는다.

구현 전에 정해야 할 것

  • 3번·Map Option 에 실제 값이 있을 때 — 지금은 CLONE·EXISTING 이어도 저장값을 그대로 보여준다. 접기(③)에 넣으면 값이 있어도 "원본 따름"으로 가려진다. 값이 있으면 접기에서 빼고 실값 칩으로 보여줄지, 지도 편차처럼 무조건 "원본 따름"으로 할지 정해야 한다. (map_type 을 CLONE 으로 바꿀 때 이 값들이 초기화되는지는 이번에 확인하지 못했다.)
  • X표시를 "원본 따름"으로 바꿀 때 — 지금은 회차 간 변경 강조와 '이력 확인'이 이 칸에 붙어 있다. 잠긴 항목이라 변경될 일이 없다고 보고 강조를 같이 없앨지 정해야 한다.
  • 접기 기본 상태 — 목업은 접힌 상태로 시작한다. 검토자가 항목명을 한눈에 봐야 하면 펼친 상태로 시작하는 쪽이 낫다.
  • export(엑셀) — utils/detailExport.ts:438 이 같은 판정(isMapRegisteredDetail)을 쓴다. "원본 따름" 문구를 엑셀에도 맞출지 정해야 한다.
  • ② 의 "동일" 판정 — 작성 화면의 EXISTING 자동 매칭 잠금(existingAutoLocked: 원본 위치 = 라인, 원본 제품 = 제품 이름 앞 코드 8자)과 같은 규칙을 쓰는 것을 전제로 그렸다.
  • 새 문구("원본 따름", 배너 문장 등)는 ko.json/en.json 에 키를 함께 추가한다(규칙 G).
