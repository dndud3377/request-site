CLONE·EXISTING 상신서 — 의뢰 상세 모달 'R' 탭 표시 개선안 (v2)

결재 현황 → 의뢰서 행 클릭 → 의뢰 상세 모달 → 'R' 탭. 왼쪽은 현재 코드(PagedDetailView.tsx)가 그리는 화면을 그대로 옮긴 것이고, 오른쪽은 개선안이다. MAP 목적·원본 위치·원본 제품 이름 칸과 기존 칩 모양은 바꾸지 않고, 잠긴 항목을 어떻게 보여줄지만 바꾼다. NEW·MAP 삭제·ADI CD 변경 문서는 바뀌지 않는다.

① 잠기지 않는 항목 — 지금 그대로

MAP 목적 · 원본 위치 · 원본 제품 이름 · Only C가문 제품 · PY 적용 여부 · Final/GDS

② 잠기는 항목이 기본값 — 칸 생략 + 요약 한 줄

지도 편차 · 예외 구역 · X표시 · C가문 세부 정보 · 3번 · Map Option 중 기본값인 것은 칸을 그리지 않고 맨 아래 한 줄에 이름만 모은다.

③ 잠기는 항목에 값이 있음 — 실제 값 + ⚠

기본값이 아니거나 회차 사이에 바뀐 항목은 NEW 문서와 같은 칸으로 실제 값을 보여준다(변경 강조·이력 확인 그대로). 절대 "없음"으로 가리지 않는다.

④ 목록에 없는 항목 — 항상 표시

접기 대상은 위 6개를 이름으로 나열한 목록뿐이다. 나중에 추가된 기능이 이 목록에 없으면 접히지 않고 그대로 보인다.
