2. 동작 흐름

① 기타 목적 선택3개 중 1개 이상 → Merge 블록 1개 노출
② 참조 요청서 선택결재완료 문서 검색 → J/O 행 로드
③ Merge 실행확인 모달 → J/O 스냅샷을 문서에 저장 → 3-way 재판정 반영 + 비교 결과 생성
④ 자동 판정1:1·한쪽만 → 변경전/변경후 표
모호 → BEFORE/AFTER 표
⑤ 수동 매핑BEFORE 1행 + AFTER 1행 선택 → 적용 즉시 확정 (해제는 ✕, 양쪽 복귀)
⑥ 게이트AFTER 가 0행이 되어야 다음 STEP·상신 가능
⑦ 저장매핑 결과 + 스냅샷 저장 → 상세 페이지 노출

재선택은 언제든 가능합니다 — 오늘 임시저장하고 내일 다시 열어도 저장된 스냅샷으로 J/O 표까지 Merge 이전으로 되돌립니다. (#21)

수동 검증 시나리오 (규칙 C-2-1)

시나리오조작 순서성공 판정
① 노출 조건의뢰서 작성 → 라인·조합법·제품·조리법 입력 → 기타 목적에서 STEPSEQ 변경 → 이어서 Layer 추가/삭제·Overlay 변경 클릭참조 요청서 블록이 1개만 노출. 3개 모두 해제하면 블록·표 사라지고 상태 초기화
② 자동 매칭참조 요청서 선택 → Merge → 확인 모달 승인J/O 표가 기존처럼 재판정되고, 아래에 요약 바 + 게이트 + 두 표 표시. 5개 값 동일 행은 어느 표에도 없음
③ 즉시 적용BEFORE 1행 클릭 → AFTER 1행 클릭 → 적용중간 단계 없이 변경전/변경후 표에 한 줄 추가. AFTER 행은 사라지고 BEFORE 행은 목록에 남음(배지 없음)
④ BEFORE 재사용같은 BEFORE 행을 다시 클릭 → 다른 AFTER 선택 → 적용두 번째 줄이 추가됨. BEFORE 표에 사용 컬럼이 없어야 정상 (#20)
⑤ 미등록 매핑BEFORE 의 미등록 → AFTER 1행 → 적용변경전 칸이 5칸 합친 미등록 한 줄, 판정 추가
⑥ 해제 복귀변경전/변경후 표에서 자동 확정된 줄의 ✕ 클릭BEFORE 행과 AFTER 행이 모두 위 표로 되살아남 (#19). 같은 BEFORE 를 이미 쓰고 있었다면 중복 행이 생기지 않아야 함. 게이트는 다시 빨강
⑦ 게이트AFTER 를 일부만 매핑한 채 다음 STEP 클릭이동 차단 + "AFTER 항목 n건이 아직 매핑되지 않았습니다" 에러. 전부 매핑하면 초록으로 바뀌고 이동 가능 (#14)
⑧ 즉시 재선택Merge 후 J-ayer 표 한 셀 수정 → ↻ 재선택 → 확인두 표가 사라지고 J/O 표가 Merge 직전 상태(수정분 포함 롤백) 로 복구, 참조 요청서 입력이 비워짐
⑨ 다음 날 재선택 ★Merge·매핑 후 임시저장 → 브라우저 닫기 → 다시 로그인 → 임시저장 문서 열기 → ↻ 재선택저장된 스냅샷으로 J/O 표가 Merge 이전으로 롤백되고 두 표·매핑이 초기화됨 (#21). 실패 신호: 버튼이 비활성이거나 J/O 가 그대로 남음
⑩ 저장·복원임시저장 → 다시 열기변경전/변경후 표와 BEFORE/AFTER 잔여 항목이 그대로 복원

잠재 이슈 · 주의사항

  • 재선택 롤백의 범위 — 스냅샷은 Merge 직전 시점이므로 Merge 이후의 수동 편집도 함께 사라집니다. ConfirmModal 문구에 명시합니다.
  • 스냅샷 정리 시점 — 재선택 완료·조리법(process_id) 변경·3개 목적 전체 해제 시 mergeSnapshot = null 로 비웁니다. 안 비우면 다른 조리법의 옛 J/O 로 롤백되는 사고가 납니다.
  • 저장 용량 — additional_notes 가 J/O 행 수만큼 커집니다(대략 1.6~2배). TextField(longtext)라 한계는 없지만, 목록 API 가 additional_notes 를 통째로 내려주므로 목록 응답이 무거워질 수 있습니다 — 필요 시 목록 직렬화에서 제외하는 별도 과제로 남깁니다.
  • 해제 시 중복 방지 — 같은 BEFORE 행이 이미 목록에 있으면 다시 추가하지 않습니다(행 id 기준). id 가 없는 자동 확정 짝은 table+5개 값 조합 키로 비교합니다.
  • 기존 매칭 키 결함 — computeLayerMerge 키에 layerid 가 빠진 알려진 문제(docs/REQUEST.md:282)는 이번 범위 밖(#8). 새 함수는 process_id+layerid 기준 — 의도된 분리입니다.
  • 구버전 문서 — merge_pairs/mergeSnapshot 없는 문서는 백필. 스냅샷이 없으면 재선택 버튼에 "J/O 롤백 없이 매핑만 초기화됩니다" 툴팁을 답니다.
