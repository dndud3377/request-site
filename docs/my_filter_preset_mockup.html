2동작 규칙 (확정 반영)

위치 ✅필터 바 안 맨 앞 드롭다운 하나('⭐ 나만의 필터 ▾'). 펼치면 위에 저장한 필터 목록(이름 + 값 요약), 구분선 아래에 '+ 현재 필터 저장'·'⚙ 관리'. 하나도 없으면 "저장된 필터가 없습니다" 안내를 보인다. 다른 필터 드롭다운과 같이, 하나를 열면 나머지는 닫히고 바깥을 누르면 닫힌다.
버튼 표시적용 중인 필터가 있으면 버튼이 강조색으로 바뀌고 이름이 '⭐ {필터 이름}'으로 바뀐다. 없으면 '⭐ 나만의 필터'.
항목 클릭 = 적용 ✅라인·목적·MAP 목적 3종을 통째로 교체한다(지금 걸린 값에 더하지 않는다). 저장값이 빈 항목은 '전체'(해제)로 바뀐다.
상신일·분류·탭·검색어는 건드리지 않는다. 1페이지로 이동한다.
적용 표시현재 3종이 저장값과 정확히 같을 때만 그 항목에 ✓, 버튼에 이름을 표시한다. 적용 후 필터를 손으로 바꾸면 표시가 꺼진다. 다른 항목을 적용했거나 손으로 같은 조합을 맞춘 경우에도 같은 규칙으로 판단한다.
✓ 항목 다시 클릭3종을 해제한다(필터 바 '초기화'와 같지만 상신일·분류는 남긴다).
값 요약목록의 각 이름 아래에 저장된 값을 작은 글씨로 보여준다(마우스 올릴 필요 없음). 예: 라인 라인1, 라인2 · 목적 신규 · MAP 목적 전체
탭 전환방금 반영한 '탭 전환 시 필터 유지'와 같다. 적용한 나만의 필터는 탭을 바꿔도 그대로 걸려 있다.
저장 ✅드롭다운의 '+ 현재 필터 저장' → 이름 입력 창(지금 걸린 3종 요약을 함께 보여줌). 3종이 모두 비어 있거나 10개가 차 있으면 비활성화하고 이유를 아래에 적는다.
이름: 필수, 최대 30자, 내 필터 안에서 중복 불가. 개수: 1인당 최대 10개.
관리이름 변경 · '현재 필터로 덮어쓰기' · 순서 변경(▲▼) · 삭제(확인 창). 변경은 즉시 서버에 저장한다.
저장 위치서버(사용자별). 다른 PC·브라우저에서도 같은 목록이 보인다. 다른 사용자와 공유하지 않는다.
선택지가 바뀐 경우나중에 라인·목적 선택지에서 빠진 값이 저장돼 있으면 적용할 때 그 값만 무시한다(빈 결과로 혼란을 주지 않도록). 값 요약에는 "(없는 값)"으로 표시한다.

백엔드 모델 (신규 · 마이그레이션 필요)
class PersonalFilterPreset(models.Model):
    """결재 현황 '나만의 필터' — 사용자별 라인·목적·MAP 목적 조합."""
    user         = ForeignKey(User, on_delete=CASCADE, related_name='filter_presets')
    name         = CharField(max_length=30)
    lines        = JSONField(default=list)   # ["라인1", "라인2"]
    purposes     = JSONField(default=list)   # ["신규", "변경 감지"]
    map_purposes = JSONField(default=list)   # ["NEW", "CLONE", "__NA__"]
    order        = PositiveSmallIntegerField(default=0)
    created_at   = DateTimeField(auto_now_add=True)

    class Meta:
        ordering = ['order', 'id']
        constraints = [UniqueConstraint(fields=['user', 'name'], name='uniq_filter_preset_name_per_user')]
